# `format/` — formatação pt-BR

Converte a saída do motor (centavos, basis points) em texto legível.

Fora do motor por C-M4 de `ADR-003`: manter a formatação aqui é o que permite
testar o motor por igualdade exata de inteiros.

O motor **não** importa deste diretório. Verificado por lint.

Começa em T-011.
